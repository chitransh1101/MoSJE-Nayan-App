Backend

The one FastAPI service that Sentinel, Setu and Nayan all talk to. This page shows how it is built and the full API reference. The demo above runs on sample data in your browser, so there is no hosted API to call here; run the backend locally with Docker to see it live.

How the backend is built

  • Framework: FastAPI on Python 3.12, with Pydantic request and response models.
  • Data: SQLAlchemy 2 with Alembic migrations; PostgreSQL in production, SQLite for local runs.
  • Security: server-side sessions revoked on sign-out, short-lived (15 min) bearer tokens, TOTP 2-step sign-in, sign-in lockout, per-IP rate limits, security headers, and a start-up guard that refuses default secrets in production.
  • Engines: a CSPRNG assignment engine with a fairness window; SHA-256 evidence check (server re-hashes every upload); Haversine geofence; statistical anomaly model; perceptual-hash frame check; and a hash-chained audit log.
  • Assistant (Yukt): retrieval over a knowledge base; a language-model provider is optional and only used when an API key is configured.
  • Run and test: Docker Compose (database, API, three web apps), plus a Windows desktop bundle; 73 automated tests run in continuous integration.
